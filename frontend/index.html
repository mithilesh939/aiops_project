      User manual

      For students and teachers

      1. Open My learning, type a student ID (suggestions appear) and press Show my topics.
      2. Each bar is the estimated chance that the student answers a question in that topic correctly. Red bars (below 50%) are weak topics.
      3. Press Suggest 5 questions to get practice questions from the weakest topics.
      4. Under Try a question, choose a topic and question, press Predict, then press Correct or Wrong to teach QuizPulse the real result.

      For operators

      1. Pipeline & models shows the model in use, its live accuracy (AUC), and whether the incoming data has changed (drift).
      2. Run drift check compares recent data with the training data. Retrain now trains a new model and only switches to it if it is better.
      3. The green dot top right means the API is reachable. Red means start the backend (docker compose up).

      Full manual: docs/USER_MANUAL.md.
